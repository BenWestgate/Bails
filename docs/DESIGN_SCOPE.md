# CipherStick Scope

## Supported now

- Bitcoin Core download, verification, installation, and pruning setup on Tails.
- Tails Persistent Storage setup guidance.
- Persistent Storage passphrase practice.
- The pinned `python-codex32` application for codex32 seed backup and recovery through Bitcoin Core.

## Not supported

- Wallet creation, recovery, or key handling outside the pinned `python-codex32` application.
- Automatic cloning or backup USB creation.
- Offline signing, air-gapped workflows, or multisignature coordination.
- Codex32 QR workflows, share rotation, inheritance workflows, and panic modes.
- AssumeUTXO bootstrap.

Ideas described in project history are not capabilities unless they appear in the supported list above. A feature becomes supported only after its implementation, tests, documentation, and review are merged.
